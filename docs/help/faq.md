## 업데이트는 어떻게 받나요?

- **Windows 설치 버전(`.exe`)**: 새 버전이 출시되면 앱 실행 시 업데이트 안내 팝업이 자동으로 표시되며, 클릭 한 번으로 간편하게 최신 버전을 적용할 수 있습니다.
- **Windows 포터블(`.exe`) / macOS(`.dmg`)**: 홈 화면의 **다운로드** 섹션에서 최신 설치 파일을 내려받아 덮어쓰시면 기존 원고와 설정은 그대로 유지된 채 업데이트됩니다.
