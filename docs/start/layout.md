## 3단 집필 레이아웃

Penso는 원고 집필과 설정 참조를 한 화면에서 처리할 수 있도록 3단 구조로 구성되어 있습니다.

- **왼쪽 탐색기**: 작품 전환, 기본 폴더 및 세부 폴더 탐색, 파일 생성·순서 정리를 담당합니다.
- **중앙 에디터**: 선택한 원고나 설정 문서를 작성하는 핵심 작업 영역입니다. 좌·우 위젯을 모두 끄면 중앙 에디터가 전체 폭을 넓게 사용합니다.
- **좌·우 위젯 영역**: 문서 참조, 특수문자, 빠른 메모, 복선 체크, 집필 타이머 등 원하는 위젯을 양쪽에 자유롭게 배치할 수 있습니다.

## 설정창

왼쪽 하단의 **설정** 버튼을 열면 집필 환경 전반을 세밀하게 조정할 수 있습니다.

- **기본 설정**: 테마(라이트·다크), 글꼴·크기·행간 등 에디터 조판 환경
- **워크스페이스**: 현재 화면 구조(드래그로 위젯 순서 변경 및 좌·우 이동)와 위젯 추가·제거
- **기능**: 등장인물 하이라이트, 자동 저장 등 편의 기능 켜기/끄기
- **템플릿**: 폴더별 기본 문서 양식 설정
- **Login Key**: 암호화 저장소 키 확인 및 기기 간 동기화 관리
- **AI 설정**: 본인 API 키 연결 및 모델 선택
- **문체 관리**: 작품별 서술 톤·어조 규칙 등록
- **데이터 관리**: Google Drive 백업 연동, 워크스페이스·프로젝트 내보내기 및 가져오기
