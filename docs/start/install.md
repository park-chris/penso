## 설치 파일 내려받기

홈 화면의 **다운로드** 섹션에서 사용 중인 운영체제에 맞는 설치 파일을 내려받습니다.

- **Windows**: 설치 파일(`Penso-Setup.exe`) 또는 무설치 포터블(`.exe`)을 내려받아 실행합니다.
  - 설치형 버전은 새 업데이트가 출시되면 앱 실행 시 안내 팝업이 자동으로 표시되며, 원할 때 바로 업데이트하거나 나중에 알림으로 미룰 수 있습니다.
- **macOS**: Apple Silicon(M1~M4, `arm64.dmg`) 또는 Intel(`x64.dmg`) 버전을 내려받아 `Applications` 폴더로 옮겨 실행합니다.

## 최초 실행 시 보안 경고가 뜰 때

무료로 배포되는 독립 개발 앱 특성상 최초 1회 운영체제 보안 경고가 표시될 수 있습니다.

- **Windows**: *Windows의 PC 보호(SmartScreen)* 창에서 **`추가 정보 → 실행`**을 눌러 설치를 진행합니다.
- **macOS**: 미서명 앱 경고가 뜨면 **`시스템 설정 → 개인정보 보호 및 보안`** 하단에서 **`그대로 열기`**를 클릭합니다.
