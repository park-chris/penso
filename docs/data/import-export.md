## 워크스페이스 내보내기 · 가져오기

**설정 → 데이터 관리**에서 Penso 전체 데이터(모든 작품, 설정, 위젯 구성 등)를 하나의 백업 파일로 내보낼 수 있습니다.

- **내보내기**: 정기적인 로컬 백업이나 새 컴퓨터로 전체 환경을 그대로 옮길 때 사용합니다.
- **가져오기**: 내보낸 워크스페이스 백업 파일을 불러와 기존 작업 환경을 그대로 복원합니다.

## 프로젝트(작품) 단위 내보내기 · 가져오기

특정 작품 하나만 따로 보관하거나 다른 기기로 옮기고 싶을 때는 **프로젝트 단위 내보내기 · 가져오기**를 사용합니다.

- 해당 작품의 원고, 세부 폴더, 설정집, 플롯·복선, 마인드맵이 함께 묶여 안전하게 이동됩니다.
